# Closing, but not Covering, the Gap

A reproduction and beyond-accuracy study of **COSETTE** and **MARIUS** (Lepage, Mary, Picard,
arXiv:2508.14910), carried out for the Master's Recommender Systems course (Group 14).

This repository builds on two upstream sources, both preserved unmodified under
[`upstream/`](upstream/):

- Original authors' code and paper: https://github.com/Simon-Lepage/cosette_and_marius
- Course head TA's fork (Amazon-2014 data pipeline and enabling fixes):
  https://github.com/2t2c/cosette_and_marius

Paper: https://arxiv.org/abs/2508.14910

## What this repository adds

We reproduce the paper's central claim that collaborative tokenization (COSETTE) and a
decoupled generative model (MARIUS) close the gap to a tuned identifier-based baseline
(SASRec++), and we then study how the generative paradigm behaves beyond accuracy. The
headline reproduces only at scale: a paper-faithful SASRec++ beats MARIUS on the small
2014 data, while MARIUS holds a small but significant advantage on the large 2023 dataset,
where it nonetheless serves a structurally narrower slice of the catalogue.

- Reproduction on Amazon-2014 (Beauty and Sports), SASRec++ and MARIUS-COSETTE, five seeds,
  Recall and NDCG: [`REPLICATION_REPORT.md`](REPLICATION_REPORT.md).
- Paper-faithful re-run with per-dataset baseline sizing that recovers most of the SASRec++
  gap: [`FAITHFUL_RERUN.md`](FAITHFUL_RERUN.md).
- Scale prong on Amazon-2023 (Arts, Crafts and Sewing, about 90,000 items), five seeds:
  [`REPRODUCTION_REPORT_AMAZON_2023.md`](REPRODUCTION_REPORT_AMAZON_2023.md).
- Beyond-accuracy extension: catalogue coverage, diversity, and popularity bias; an exact
  full-catalogue oracle that locates the concentration in the trained model rather than the
  beam search; and mitigation levers across pipeline stages:
  [`EXTENSION_RESULTS.md`](EXTENSION_RESULTS.md).

Figures and per-experiment outputs live under [`reports/`](reports/). Working notes and
archived pilot experiments live under [`docs/`](docs/).

## Reproducing

```bash
pip install -r requirements.txt
pip install -e .
```

The full download-and-train pipeline runs on SLURM. See [`jobs/RUN_ORDER.md`](jobs/RUN_ORDER.md)
for the Amazon-2014 order and [`REPRODUCTION_REPORT_AMAZON_2023.md`](REPRODUCTION_REPORT_AMAZON_2023.md)
for the Amazon-2023 pipeline. Datasets and large training outputs are regenerated by the
pipeline and are not stored in the repository. The beyond-accuracy metrics and the oracle run
offline from the committed model outputs and need no GPU.
